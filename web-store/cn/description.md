### Long Description

英语初学者常常因为词汇量不足而无法坚持阅读英文文章。本软件自动展示生词含义，改善阅读体验，让英文阅读变得丝滑，让读者体会文章内容带来的快乐。俗话说大巧不工，重剑无锋，大量的阅读胜过一切看似巧妙的学习方法。

主要功能如下：
1. 个人词汇表的初始化/导入/导出。
2. 根据个人词汇表，在网页中自动显示生词的含义。
3. 灵活的注解功能，支持显示含义，音标，笔记。
4. 在阅读过程中标记单词为认识/不认识, 从而更新个人词汇表。
5. 支持词根词缀记忆法
6. 查看阅读报告
7. 对网页内容进行高亮，笔记。
8. 支持epub/pdf格式的电子书（小说，外刊等），以及绝大部分英文网站。
9. 导入用户词典，支持Mdict格式


原名：我的英文阅读助手/My English Reading Assistant

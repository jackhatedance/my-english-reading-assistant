### Long Description

英语初学者常常因为词汇量不足而无法坚持阅读英文文章。本软件自动提示生词含义，改善阅读体验，让英文阅读变得丝滑，让读者感受文章内容带来的快乐，并在不知不觉中提高英语水平。

主要功能如下：
1. 个人词汇表的初始化/导入/导出。
2. 根据个人词汇表，在网页中自动显示生词的含义。
3. 灵活的注解功能，支持显示含义，音标，笔记。
4. 在阅读过程中标记单词为认识/不认识, 从而更新个人词汇表。
5. 支持词根词缀记忆法
6. 查看阅读报告(每日阅读时间统计，词汇量变化，阅读速度变化等)
7. 对网页内容进行高亮，笔记。
8. 支持epub/pdf格式的电子书（小说，外刊等），以及绝大部分英文网站。
9. 导入用户词典，支持Mdict格式，支持英汉，英英词典。


原名：我的英文阅读助手/My English Reading Assistant

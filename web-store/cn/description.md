### Long Description

英语初学者常常因为词汇量不足而无法坚持阅读英文文章。本软件可以免去读者不停查字典的痛苦，克服因为词汇量不足而造成的阅读困难。多次看到的生词，不知不觉就会记住其含义了，并且语境中的单词更不容易被遗忘。让读者尽可能享受文章内容带来的快乐。

主要功能如下：
1. 个人词汇表的初始化/导入/导出。
2. 根据个人词汇表，在网页中自动显示生词的含义。
3. 在阅读过程中标记单词为认识/不认识, 从而更新个人词汇表。
4. 支持词根词缀记忆法
5. 查看阅读历史。
6. 对网页内容进行高亮，笔记。
7. 支持epub/pdf格式的电子书（小说，外刊等），以及绝大部分英文网站。
8. 导入用户词典，支持Mdict格式

原名：我的英文阅读助手
